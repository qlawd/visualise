## Install

```bash
git clone https://github.com/qlawd/visualise ~/.claude/skills/visualise
```

That's it. One command.

## Usage

In any Claude Code session:

```
/visualise microservice architecture of this repo
/visualise git branching strategy as a state diagram
/visualise correlation between these features
/visualise the auth flow as an animated state machine
/visualise bundle sizes in package.json
```

Claude reads your codebase, picks the right visualization type, generates a self-contained HTML file, and opens it in your browser.

Then iterate:

```
> make the nodes bigger
> add a legend
> color by module instead of type
> add zoom and pan
```

## How It Works

```
You type /visualise <topic>
    |
    v
Claude reads context
    (files, data, architecture, concepts)
    |
    v
Picks visualization type
    |
    v
Generates self-contained HTML
    (D3 / Canvas / SVG, dark theme, interactive)
    |
    v
Opens in your browser  <-- iterate from here
```

The skill teaches Claude which visualization type fits which topic:

| Topic | Visualization |
|---|---|
| Relationships / dependencies | Force-directed graph |
| Flows / pipelines | Sankey diagram |
| State machines / processes | Animated state diagram |
| Hierarchies / file trees | Treemap or radial tree |
| Time series / performance | Interactive line chart |
| Comparisons / tradeoffs | Parallel coordinates |
| Correlations / matrices | Heatmap |
| Distributions | Histogram + box plot |
| Architecture | Box-and-arrow with zoom |
| Concepts with parameters | Sliders + live canvas |

## Design Principles

- **Single file.** Everything inline. No build step. Share by sending an HTML file.
- **Dark theme.** Developers live in dark mode. The visualizations match.
- **Interactive first.** Every output has hover, click, drag, or animation. Static images are for Matplotlib.
- **Real data.** When connected to a codebase, uses actual file names, actual dependencies, actual metrics.
- **Iterate in conversation.** "Make the nodes bigger." "Add a legend." "Color by module."

## Customizing

Fork the repo and edit `SKILL.md` to change defaults:

- **Color palette** — swap the 7 accent colors in the Design Language section
- **Theme** — change to light theme by editing the background/text colors
- **Visualization types** — add new mappings to the topic-to-viz table
- **Output path** — change where generated files are saved

## Local Gallery Preview
